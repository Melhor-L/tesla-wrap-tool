# 特斯拉涂装生成器（Tesla Wrap Tool）

一个**纯前端**的特斯拉车衣涂装设计工具，用于生成适配「玩具盒 → 喷漆车间 → Wraps」格式的 1024×1024 PNG 涂装贴纸。

用户可按车身固定区域独立贴膜：**点选膜片部件 → 上传图片 → 拖拽/缩放/旋转调整 → 固定 → 导出 PNG**，全程浏览器本地完成，图片不上传服务器。

**在线体验**：https://tesla-wrap-tool.app.workbuddy.host/?sharecode=S23KIBRFY5

---

## 功能特性

- 🚗 **多车型模板**：内置 10 款车型（Model 3 / Model Y 各 3 个年款、Model S、Model X、Cybertruck），支持上传自定义模板（GitHub [custom-wraps](https://github.com/teslamotors/custom-wraps) 任意车型）
- 🧩 **部件点选绑定**：在预览图上点击车身膜片部件（可多选），精确绑定到指定区域
- ✂️ **手动切割**：车头/机盖等在模板中实心连成一片时，用「切割模式」画线切开，使其成为独立可选区域；支持「回退切割」撤销
- 💾 **切割模板导出/导入**：切割结果可导出为 JSON 文件永久保存，下次导入即可恢复；部分车型内置了默认切割，加载即用
- 🔒 **锁定/解锁**：锁定后点击画布变拖拽，避免误取消部件；可解锁重新选
- 🖱️ **灵活调整**：拖拽定位、缩放（10% ~ 1000%）、旋转（0° ~ 360°）、双指捏合缩放（移动端）
- 🎨 **空白填充**：选色板填充未贴图区域
- 🖼️ **边框开关**：显示/隐藏部件彩色轮廓，描边画在间隙中避免部件粘连
- 📱 **移动端适配**：预览图吸顶固定、触控按钮放大、单指拖拽 + 双指缩放
- 📤 **分享晒图**：生成带工具名 + 链接水印的竖版分享图（1080×1440），便于朋友圈/小红书传播
- 💾 **导出 PNG**：1024×1024、≤1MB、自动规范命名

## 使用说明

### 操作流程

1. **选择车型模板**（第 0 步）：下拉选择车型，或选「自定义模板」上传自己的模板 PNG

2. **选择车身区域**（第 1 步）：点击 5 个区域标签之一：车头 / 左侧 / 右侧 / 车尾 / 车顶

3. **绑定部件**（第 2 步）：在预览图上**点击膜片部件**（可多选），选完后点「锁定部件」

4. **上传图片**（第 3 步）：上传 JPG/PNG，图片贴到当前区域绑定的部件上，拖拽/缩放/旋转调整

5. **固定**：满意后点「固定到当前区域」（固定后不可再调整）

6. **可选：填充空白**（第 4 步）：给未贴图区域填充颜色

7. **下载 PNG / 分享晒图**：所有区域固定后导出

### 颜色标识说明

| 颜色 | 含义 |
|------|------|
| 🔵 蓝色边框 | 未绑定到任何区域的部件 |
| 🔴 红色边框 | 已绑定到当前选中区域 |
| 🟠 橙色边框 | 已绑定但未固定的部件 |
| 🟢 绿色边框 | 已固定区域占用的部件 |

### 状态流转

```
点选部件(未锁定) → 锁定 → 上传图片 → 拖拽/缩放/旋转 → 固定(锁死) → 导出
                              ↑____________________________|
                          取消固定可恢复调整 · 解锁可重新选部件
```

## 核心实现原理

### 1. 模板解析
读取模板 PNG 的 **alpha 通道**：白色膜片区域（alpha > 0）即车身部件，透明间隙为镂空。

### 2. 连通域分析
用 **BFS（广度优先搜索）** 遍历 alpha 通道，识别出模板中每个**独立的膜片部件**（如 Model 3 2022 有 13 个连通域），作为可点选绑定的最小单元。

### 3. 区域绑定
每个固定区域维护一个**部件 ID 集合**（`Set`）。区域掩码 = 其绑定部件的掩码并集。

### 4. 间隙边缘描边
描边线画在**部件外侧的透明间隙**里（而非部件内部边缘），避免窄间隙被两侧描边填满而视觉粘连，保证相邻部件有清晰分隔线。

### 5. 渲染合成
```
对每个区域：
  1. 新建独立 Canvas 层
  2. drawImage 绘制图片（含平移 + 旋转 + 缩放）
  3. 用区域掩码裁剪（掩码外 alpha 置 0）
  4. 叠加到主画布
最后叠加部件彩色边框（预览用，导出时不含）
```

### 6. 导出
只渲染「已固定区域 + 填充色」，生成 1024×1024 PNG，文件名自动规范（`Tesla_Wrap_日期.png`）。分享图额外合成 1080×1440 竖版带水印。

### 7. 切割模板持久化
切割线被记录为 `cutMask`（被切开像素的掩码）。导出时仅保存**被切割像素的稀疏索引**（而非全量 `W×H` 掩码），JSON 体积小；导入时按索引重建掩码并重新做连通域分析。部分车型的预设切割结果内置在 `DEFAULT_CUT_TEMPLATES` 常量中，加载对应车型时若切割掩码为空则自动应用，作为「开箱即用」的默认切割。


## 开发历程备忘

项目最初尝试用 `@imgly/background-removal` 做浏览器端 AI 自动抠图，但因模型文件需从国外 CDN 下载（国内访问慢）、且 esm.sh 导出结构不匹配（命名导出 vs default 导出）等问题，最终改为**「不抠图、直接分区贴膜」**方案，体验更可控、更轻量。
